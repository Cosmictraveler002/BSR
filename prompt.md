# Meet Me Cafe — Checkout & Order JSON Construction Specification

> **System Prompt / Task Instruction**:  
> Use this prompt to implement or generate the client-side checkout logic, cart payload serialization, and API integration for the **Meet Me Cafe** web application. This connects the Cafe frontend directly to the centralized backend on `bangalirsokherrannaghor.in`.

---

## 1. Production API Endpoints & Authentication

- **Primary Order Endpoint**: `https://bangalirsokherrannaghor.in/api/orders`
  - **Method**: `POST`
  - **Headers**:
    - `Content-Type: application/json`
    - `X-Brand-Key: mm_live_cafe_2026`
- **Order Tracking Endpoints**:
  - `GET https://bangalirsokherrannaghor.in/api/orders/{order_id}`
  - `GET https://bangalirsokherrannaghor.in/api/orders/track/{phone}`
- **Table Reservation Endpoint**:
  - `POST https://bangalirsokherrannaghor.in/api/reservations`
- **Brand & Outlet Configuration**:
  - `brand`: `"cafe"` (case-insensitive, normalized to lowercase)
  - `outlet_id`: `"MM01"` (Meet Me Kalyani branch)
- **Order ID Format**:
  - Automatically generated by backend: `MM-MM01-2026-XXXXXXXX`
- **Server-Side Protection Constraints**:
  - **Payload Size Cap**: Max 64 KB (requests > 64KB rejected with `413 Payload Too Large`).
  - **Cart Size Cap**: Max 30 line items per order (rejected with `422 Unprocessable Entity` if > 30).
  - **Rate Limiting**: Max 30 orders/minute per IP address (`429 Too Many Requests`).
  - **Phone Flood Guard**: Max 5 orders per phone number per 10-minute window (`429 Too Many Requests`).

## 2. Exhaustive JSON Schema Specification

```typescript
interface MeetMeCafeOrderPayload {
  customer_name: string;        // Required. Length: 2 to 100 characters. Clean human name.
  customer_phone: string;       // Required. Length: 5 to 20 characters. Regex: ^\+?[0-9\s\-]{5,20}$
  order_type: "Dine-In" | "Takeaway" | "Delivery"; // Required. Strict enum.
  table_number: string | null;  // Required for "Dine-In" (e.g. "Table 04", "T-02"). Null for Takeaway/Delivery.
  delivery_address: string | null; // Required for "Delivery" (max 300 chars). Null for Dine-In/Takeaway.
  outlet_id: "MM01";            // Required. Meet Me Kalyani branch identifier.
  brand: "cafe";                // Required. Always lowercase "cafe".
  coupon_code: string | null;   // Optional promotional code or null.
  items: Array<{
    id: string;                 // Required. Item SKU/slug (e.g. "mm-cappuccino-hazelnut"). Max 50 chars.
    name: string;               // Required. Display dish/beverage title (e.g. "Hazelnut Cappuccino"). Max 150 chars.
    price: number;              // Required. Unit price in INR (e.g. 180.0). Non-negative float.
    qty: number;                // Required. Integer between 1 and 100.
  }>;
}
```

## 4. Field Validation & Sanitation Rules

| Field Name | Type | Constraints | Backend Behavior |
| :--- | :--- | :--- | :--- |
| `customer_name` | String | 2–100 chars | Strips HTML/script tags automatically; rejects empty/whitespace names. |
| `customer_phone`| String | 5–20 chars | Validated against regex `^\+?[0-9\s\-]{5,20}$`. Accepts country code. |
| `order_type` | Enum | `"Dine-In" \| "Takeaway" \| "Delivery"` | Strict enum. Rejects any other value with `422 Unprocessable Entity`. |
| `table_number` | String/Null | Max 50 chars | Preserved if `Dine-In`; ignored/null if Takeaway/Delivery. |
| `delivery_address`| String/Null| Max 300 chars | Required if `Delivery`; stores customer dropoff instructions. |
| `outlet_id` | String | Exactly `"MM01"` | Automatically normalized to `"MM01"` for Meet Me Kalyani. |
| `brand` | String | Exactly `"cafe"` | Normalized to lowercase `"cafe"`. Flags record for cafe-only queues. |
| `coupon_code` | String/Null | Max 30 chars | Evaluated against active promotions or stored as `null`. |
| `items` | Array | `min_items: 1`, `max_items: 100` | Rejects empty cart with `400 Bad Request`. |
| `items[].id` | String | 1–50 chars | Clean SKU slug without HTML markup. |
| `items[].name` | String | 1–150 chars | Clean display name. |
| `items[].price` | Number | `>= 0.0` | Line totals computed as `round(price * qty, 2)`. |
| `items[].qty` | Integer | `1 <= qty <= 100` | Integer multiplier per line item. |

## 5. Client-Side Implementation Blueprint (Vanilla JavaScript)

```javascript
/**
 * Constructs and submits the Meet Me Cafe order payload to the backend API.
 * @param {Object} cartState - Cart state object containing customer inputs and items array.
 * @returns {Promise<Object>} Created order confirmation response from server.
 */
async function submitMeetMeCafeOrder({
  customerName,
  customerPhone,
  orderType, // 'Dine-In' | 'Takeaway' | 'Delivery'
  tableNumber = null,
  deliveryAddress = null,
  couponCode = null,
  cartItems = [] // Array of { id, name, price, quantity }
}) {
  // 1. Client-Side Defensive Validations
  if (!customerName || customerName.trim().length < 2) {
    throw new Error('Please enter a valid customer name.');
  }
  if (!customerPhone || !/^\+?[0-9\s\-]{5,20}$/.test(customerPhone.trim())) {
    throw new Error('Please enter a valid 10-digit contact phone number.');
  }
  if (!cartItems || cartItems.length === 0) {
    throw new Error('Your cafe order cart is empty.');
  }
  if (orderType === 'Dine-In' && (!tableNumber || !tableNumber.trim())) {
    throw new Error('Please enter your table number for Dine-In service.');
  }
  if (orderType === 'Delivery' && (!deliveryAddress || !deliveryAddress.trim())) {
    throw new Error('Please enter a complete delivery address.');
  }

  // 2. Construct Standardized Meet Me Cafe Payload
  const payload = {
    customer_name: customerName.trim(),
    customer_phone: customerPhone.trim(),
    order_type: orderType,
    table_number: orderType === 'Dine-In' ? tableNumber.trim() : null,
    delivery_address: orderType === 'Delivery' ? deliveryAddress.trim() : null,
    outlet_id: 'MM01',
    brand: 'cafe',
    coupon_code: couponCode ? couponCode.trim() : null,
    items: cartItems.map((item, idx) => ({
      id: item.id || `mm-item-${idx + 1}`,
      name: item.name.trim(),
      price: parseFloat(item.price),
      qty: parseInt(item.quantity || item.qty || 1, 10)
    }))
  };

  // 3. Resolve API Endpoint
  // In production, send directly to your live backend domain
  const API_ENDPOINT = 'https://bangalirsokherrannaghor.in/api/orders';

  // 4. Dispatch HTTP POST Request with Brand Key
  const response = await fetch(API_ENDPOINT, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'application/json',
      'X-Brand-Key': 'mm_live_cafe_2026'
    },
    body: JSON.stringify(payload)
  });

  if (!response.ok) {
    const errorBody = await response.json().catch(() => ({}));
    const message = errorBody.detail || `Server returned HTTP ${response.status}`;
    throw new Error(`Order placement failed: ${message}`);
  }

  const orderResult = await response.json();

  // 5. Persist to Local Customer History (optional)
  try {
    const history = JSON.parse(localStorage.getItem('mm_cafe_order_history') || '[]');
    history.unshift(orderResult);
    localStorage.setItem('mm_cafe_order_history', JSON.stringify(history.slice(0, 20)));
  } catch (e) {
    console.warn('Could not persist order to localStorage', e);
  }

  return orderResult;
}
```

## 6. Server Response Contract

### Success Response (`201 Created`)
```json
{
  "id": "MM-MM01-2026-22674859",
  "customer_name": "Arunabha Sen",
  "customer_phone": "9830012345",
  "order_type": "Dine-In",
  "delivery_address": null,
  "table_number": "Table 05",
  "items": [
    { "id": "mm-cold-brew", "name": "Classic Meet Me Cold Brew", "price": 160.0, "qty": 2 },
    { "id": "mm-croissant", "name": "Almond Butter Croissant", "price": 190.0, "qty": 1 }
  ],
  "subtotal": 510.0,
  "discount": 0.0,
  "coupon_code": null,
  "total": 510.0,
  "status": "Confirmed",
  "outlet_id": "MM01",
  "brand": "cafe",
  "created_at": "2026-10-19T10:43:04.629794"
}
```

### Error Responses
- **`400 Bad Request`**: Cart is empty or invalid data format.
- **`403 Forbidden`**: Missing or invalid `X-Brand-Key` header.
- **`413 Payload Too Large`**: Request body exceeds 64 KB.
- **`422 Unprocessable Entity`**: Field validation failed (e.g. invalid phone format or > 30 items in cart).
- **`429 Too Many Requests`**: Rate limit exceeded (more than 30 orders/min per IP or > 5 orders/10 mins per phone).
